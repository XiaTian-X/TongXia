## `run.py` 改了什么

`check_env(python="python3")`:`shutil.which` 找 PATH 上的 `python3`;问它的主.次版本,与跑 `run.py` 的 `sys.version_info` 比;
再让它 `import pytest`。返回问题说明的列表。`main` 在 `--list` 之后、`run()` 之前调用:有问题就把说明写到 stderr、不跑、返回 3。
`--list` 不自检。输出点名两边的版本(与路径)、缺 pytest 的是哪个 `python3`,并给出修法。
