不在孤儿位置的未跟踪系统文件,既不提交、也不参与写权限边界判定;孤儿位置照旧按 W31 拒绝。

## 用例 `test_v1_os_files_left.py` 8 条,今天红 5 条

- 绿:对照组(没有系统文件时输出不含 `.gitignore`);评审回合不挡(今天它被提交了所以绿,照原契约实现则红);根目录的照旧被拒。

## 参考实现与探针

`entries` 算出之后筛掉"未跟踪、名字在 `OS_FILES`、不是孤儿"的那批(`os_left`),写权限边界与其余判定都看不见它们;
`git add -A` 之后 `git reset -q -- *os_left`;"已交接"之后点名。全套 552 OK。
- 只不提交、照旧判越界(原契约)→ 红 2(不挡 dev、评审不挡)
- 拆掉不提交那一步 → 红 4
- 孤儿也放过 → 红 5(本项 1 + W31 4)
