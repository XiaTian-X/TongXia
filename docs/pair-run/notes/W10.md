(改一个 `if` 的条件),对**还没写出来的**分支不知道。W3/W4 那五条当时能补,

  **这正是 W4 那条决策的出发点**,绕回原地

**我的提议(要人类或对方定):** W10 的变异点归进 **W7**。W7 是 `cover`、

## 四、否掉的

- **断言拒绝文案的措辞**(如"重钉"两个字)—— 契约只写了"打印重钉命令",
  没规定怎么说。只断言文案里同时出现两个路径,那是"能让人照着做"的最低限度
- **`assertIn(sha, body)` 用全长 sha** —— dev 写 7 位缩写也合规。改成
  `sha[:7] in body`,而且 sha 由用例现算,不写死
- **拿 `commit_count()` 断言重钉多提交了一次** —— 重钉是搭在 DONE 那次提交上的,
  不该多一次;写成断言反而会把正确实现判死
