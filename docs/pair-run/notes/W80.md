## 行为来源

读了 `test_docs_consistency.py` 里的检查:
- `check_symbol_refs` 对 `<路径>#<符号>` 先 `_resolve` 出仓库相对路径,再查 `_symbol_index(rel)`。
- `_symbol_index` 用 `ast` 遍历 def/class(含类内方法与嵌套函数,记限定名)和模块级 `Assign` 的名字,建 `{裸名: [限定名…]}`,按文件缓存。
- 整条路径上**没有一处用到行号**:行号只在旧形式 `<路径>:<行号>` 那一支里用来给改写建议(`_enclosing_symbol`)。
- 所以"插入无关行不会红"是结构性成立的,这一项只是把它钉成用例。两条对现有检查都绿,探针变异后变红(见上表)。

## 我冻结了哪些可疑行为

- **符号缓存按文件路径记、不看内容**:同一次运行里被引文件改了,`_symbol_index` 仍返回旧索引。真实文档检查里被引文件在一次运行中不会变,不是缺陷。
  但它让"插行后仍通过"这类用例可能恒真,所以用例里每次改写都清掉缓存,上面也写明了。冻结的是"按路径缓存"这个现状,没有断言它。
- **插的无关行里有新函数(`_noise_*`)**:它们进了索引,但与被引符号不同名、不造成重名。插的是"无关的定义",不只是注释与空行 —— 比契约说的"无关行"更强一点,没有放宽。
- 其余逐条对过契约「文档里的代码引用」:只认名字、包括嵌套与方法、模块级赋值算符号。没有发现与契约不一致的行为。
