### 2. 有一处契约要求,我**故意没有**写测试

### 3. 期望值用的是终端输出,不是写死的字符串

每条比对都是「终端注入了什么 → 简报里就该是什么」。这不是图省事:
契约的「不做」要求两处来自**同一次取值**,而写死期望值恰恰测不出
"两处各算一遍" —— 只要两次算法一样,结果也一样,写死值照过。
"两处必须逐字相同"是那条要求唯一可观测的形态。

所以**别为了让测试好过而在简报侧单独算一次**,那会同时违反契约的「不做」。
