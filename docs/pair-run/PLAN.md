# 项目规划（冻结 — agent 只读）

> 由人类维护。工作项完成时由脚本勾选,那是脚本的权限,不是 agent 的。

## 目标

把 `status` 的**回合简报**做完。头部四行已经在上一轮(W1)落地并有测试守着;
这一轮补上它真正要留的东西 —— **记忆段落**,以及写不成时的降级。

来源:`docs/improvements.md` 的 P1-4。**它现在只做了 1/3** ——
P1-4 的存在理由是"agent 说'我没看到那条决策'时无从对质",而当前落盘的
四行头部里恰好没有那条决策。W2/W3 的编号沿用上一轮的拆分,
`docs/dogfood-run-1.md` 与 `tests/conformance/test_v1_brief.py` 都引用了它。
