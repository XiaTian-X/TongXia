# 项目规划（改动要带 `--contract-change` 并当场留决策）

> 方向由人类定。**两个角色都可以落笔**,但改它的那次交接要带
> `--contract-change "<指向一份真实产物的路径>"`,并在 `DECISIONS.md` 里
> 当场追加一条 —— 不是放行,是强制留痕。工作项完成时由脚本勾选,
> 那一次写入不算 agent 的改动。

## 目标

**第五轮:把测量工具修准。** 下一轮要做的是这个项目四轮来一直欠着的那件事
—— **一次两边都没参与设计的独立运行**。那是一次性、昂贵的实验,占用两个
全新会话与几十个回合,而且跑完不会有人想再跑一遍。

**所以这一轮先修仪器。** 现在有三处同时在说谎:

| 仪器 | 现在说的 | 实际 |
|---|---|---|
| 开工前契约审查这道门 | `setup_verified` 为真 = 有人读过契约 | 它**一旦为真就永不复位**,契约改了也不要求重读 |
| `report` 的「每工作项回合数 7.9 ok」 | 节奏正常 | 第四轮 10 个 impl 回合里 **2 个是空转的**(口径见契约) |
| `report` 的 `--no-decision` / `--contract-change` 两行 | 声明频率 | 带了不生效的声明**照样计数**,随手带一次就涨一格 |

**拿一个会给出错误诊断的仪器去做一次性实验,样本是废的** ——
而"一个会给出错误诊断的指标比没有这个指标更糟"是这个项目自己写下的话
(`docs/improvements.md` 的 P1-8)。

来源:开放条目 12/13/17、P1-8,以及第四轮 `DECISIONS.md` 里人类裁决的
五条中的三条。

### 人类已经裁决的五条(2026-09,第四轮收尾)

   决策」—— 它在第四轮**挡过一次整轮收尾**。→ 本轮 **W13**
2. **改**:声明只在实际生效时才写进提交正文(`--no-decision` 一并)。
   → 本轮 **W14**
3. **划掉** W9 那条已确认是死代码的验收标准。→ **本节下面已执行**

   → 已写进契约的「术语」一节,无需工作项
5. **加** `roadmap_file` 配置键。→ **本轮不做**,理由见下

**第 5 条为什么不做:** 它不是仪器,也不挡任何事 —— `--basis` 对下游项目
不触发是个真缺口,但它不影响下一轮那次实验的可信度。本轮已有三项。

### 开工前

1. **重跑 `verify-setup`** —— 契约新增三节。
2. **这一次的契约审查用一个没有任何上下文的 agent 做**,`--drafter other`。
   历次九次声明里**八次是自审**,只有第四轮 tester 那一次是 `other` ——
   而每一次自审结论开头都写着"本结论证明力打折",然后照样开工了。
   这既是补那格空白,也是下一轮那次实验的**彩排**:先看看没有上下文的
   agent 读这份契约能读懂多少。
