# W83 review-impl —— 每个待办项都认领不了时,`whose-turn` 停下交给人类

**裁决:通过(approve)。** 实现与契约逐条对上,与我在 spec 回合写的参考实现同形。没有针对用例输入的特判。

## 查过的地方

- **判点**:`cmd_whose_turn` 在篡改检查之后、`print("turn …")` 之前,只在 `phase == "idle"` 时调 `idle_claim_blocked`。
  - 现有四种 `stop` 都在它前面。
  - 进行中整段跳过,副本与认领检查都不判。
  - 归属是 dev 时同样判:判在 `phase_owner` 之前,不看归属。
- **同一份判定**:类型合法从 `cmd_claim` 的 `die` 挪进 `check_item_preconditions` 第一条,文案逐字未变。
  - `cmd_claim` 里原来的位置是"已完成"之后、`check_item_preconditions` 之前,挪进去之后先后顺序一样,`claim` 对非法类型的行为不变。
  - `check_item_preconditions` 别无其他调用方(只有 `cmd_claim` 与新函数),这次挪动不影响 `verify-setup`。
- **`idle_claim_blocked`**:
  - 先判 `judge_in_sync`(没有副本时为真),不一致直接返回,理由里有"人类""重钉"。
  - 再遍历 `_plan_blocks`,跳过已完成项。它的 `done` 与类型取法与 `parse_plan` 同一个 `ITEM_RE`。
  - 遇到第一项放行即返回 None;全被拦时取每条理由的头一行,去掉 `拒绝认领 —— ` 前缀与行尾半角/全角冒号,`<ID>:<头一行>` 用 `;` 连接。
- **只读、退出 0**:新函数只读文件。`check_item_preconditions` 读契约用 `_read`(读不到返回空串),不会抛。输出一行,以 `stop ` 开头。
- **文档**:
  - command-reference §6.6 改成六种理由并分条说明。
  - protocol-spec §3.3 补一段,troubleshooting 新节,开放条目 62 标 ✅,与契约一致。
  - 不进 `ENFORCEMENTS`,符合契约。

## 契约没要求的事(本回合重点查的那条)

1. **`if not blocked: return None`**:没有未完成项时返回 None。PLAN 全部完成早被前面的 `stop` 接住,走到这里只剩"PLAN 一个工作项都没有",契约把它列在「不做」(`verify-setup` 已判失败)。照旧 `turn`,不改变任何已定行为。
2. **副本那条文案多写了处理办法**("把正本复制成副本并提交")。只是提示文字,不改判定。
3. **类型合法并进函数**,是"与 `claim` 用同一份判定"最直接的落法,不是越界。

## 不阻断的一处文字

protocol-spec §3.3 新段说"下面工作项级的认领检查(类型合法及之后几条)",而下面那张清单里"类型合法"之后紧跟的是 `state.json` 未被篡改与裁判副本两条。

- 篡改是契约明说**不算**的角色级检查。
- 行为上没有差别:篡改本来就先走现有那条 `stop`。
- 只是字面范围偏宽。可以在收尾时顺手改成"工作项级那几条(类型合法、契约小节、待澄清标记、refactor 保护测试)",不值得为它打回一轮。

## 变异点

登记 14 个(`认领不了_` 前缀),`--only 认领不了_` 全被抓到,基线全绿:

| 变异点 | 抓到它的用例(之一) |
|---|---|
| 不判 | `test_refactor_没声明保护测试` |
| 进行中也判 | `test_进行中其余项和当前项都被拦_照旧轮到当前阶段的归属` |
| 已完成项也算 | `test_已完成项能认领_未完成项被拦_停下` |
| 任一被拦就停 | `test_一项被拦_一项能认领_照旧轮到_tester` |
| 不判副本 | `test_idle_时副本不一致_停下_要人类重钉` |
| 进行中也判副本 | `test_进行中副本不一致_照旧轮到当前阶段的归属` |
| 理由不点名工作项 | `test_refactor_没声明保护测试` |
| 多项只报第一项 | `test_三项都被拦_每一项都点名` |
| 写成多行 | `test_三项都被拦_每一项都点名` |
| 不去前缀 | `test_refactor_没声明保护测试` |
| 类型非法不拦 | `test_非法类型被拒绝`(既有用例,claim 侧) |
| 排在现有 stop 之前 | `test_尚未通过校验且所有项被拦_仍是校验那一条` |
| 只在归属 tester 时判 | `test_所有项被拦时停下_不是轮到_dev` |
| 副本文案不提重钉 | `test_idle_时副本不一致_停下_要人类重钉` |

契约列的 8 个变异点都在里面。
