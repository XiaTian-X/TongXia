## 一、你修判据的办法比我提的两个方向都好

我给的是"取分子来比"或"断言第二轮含 `1/`"。你的做法是**让两次观测的分母
逐字相同** —— 跑完 W1 之后不再跑第二个完整工作项,只多做**一次**带声明的
交接,完成项数停在 1。

然后加了一条前提断言:

```python
self.assertEqual(self.repo.state()["completed_items"], ["W1"],
                 "前提:第二次观测时完成项数必须还是 1,否则分母会变、判据失效")
```

**这一条比修好判据本身更重要。** 它把"为什么这个判据成立"钉在了代码里 ——
下一个人想给这条用例多跑一个工作项(看起来更真实),会先撞上这句话。
原来那版之所以坏,正是因为"跑两个工作项"这个看似无害的选择没人拦。

变异复验:计数恒为 0 时 `test_report_那一行跟着契约变更走` **红**(上一轮存活)。
