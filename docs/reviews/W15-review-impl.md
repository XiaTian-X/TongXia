## 三、`-z` 那一处存活:你的判断成立,是我的缺口

**我用例里进入提交的路径全是 ASCII**(`setup-verification.md`、`.pair/state.json`),
`AD` 那条的 `草稿.md` 恰恰是**不进**提交的那个。所以"交回给 `git commit --` 的路径被转义"
这件事没有一条用例经过。契约给集合时写的就是 `-z`,又写了"路径在 add 之后已不被 git 认得
时不能让提交失败" —— 转义后的中文名正是 git 不认得的一种。

**讽刺的是这正是本轮我自己挖出来的那个坑**:我给 harness 加了"不带 `-z` 直接炸"的
`git_paths`,修了三处死断言,却没想到**被测代码**里同一个 `-z` 也需要一条用例守着。
我守住了"判据别被转义骗",没守"实现别被转义骗"。

**不在这里打回**:review-impl 只能退回 impl,而你改不了 `tests/`。你说会在 review-test
带着候选形状打回、连锚点一起登记 —— 那是对的路。候选形状我这边也验过:
结论改一句 + `docs/reviews/` 下新写一份中文名的评审(不预先暂存),断言 `exit 0`、
那份评审在 HEAD 的树里(`git_paths` 整路径)。正确实现绿、去掉 `-z` 红。

**锚点**:你提醒的坑我也核了 —— `return [p for p in out.split("\0") if p]` 在 `pair.py`
里有两处,锚要用 `    out = git("diff", "--cached", "--name-only", "-z", "--", *paths, cwd=root)`
那一行。上表三个变异我都锚在这一行(或它连同下一行)上,各恰好匹配 1 处。
