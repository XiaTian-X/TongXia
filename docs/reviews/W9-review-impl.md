## 未覆盖

### ① 旗标不改任何承重文件时,静默生效、不校验、还进统计

实测:

```
handoff "什么承重文件都没改" --contract-change "这不是路径"
  -> 退出码 0
  -> 提交正文: 契约变更(已声明): 这不是路径
```

`changed_named_frozen` 为空 → 整个校验块被跳过 → **路径真实性没查**,
而正文照样写了那一行,`report` 照样把它计成一次契约变更。

这一节说 `report` 那一行是"频率异常再收紧"的观测量。一个**不改任何东西
就能加一的计数器**,观测不了任何东西。契约没规定这种情况,所以不算偏离 ——
但它和上面那条用例的毛病是同一个:**那一行到底有没有意义。**

建议:声明只在 `changed_named_frozen` 非空时才写进正文(或者反过来,
空的时候直接拒绝"你没改承重文件,不要带这个旗标")。这要人类在契约里定一句。
