## 二、11 个变异:逐格复现

| 变异 | 红的 |
|---|---|
| `--no-decision` 恒写 | 不留痕三条 + `test_不生效的声明不计数` |
| `no_decision_is_read` 不看 `settled` | **只有**笔记已沉淀那条 |
| `--doc-reason` 恒写 | **只有**没碰规范性文档那条 |
| `--basis` 恒写 | **只有**纯追加那条 |
| `--contract-change` 恒写 | 没碰承重文件 + 完成时勾选 PLAN |
| `--allow-deletion` 恒写 | **只有**没删测试那条 |
| 判定行只在空转时写 | 未判定两条 |
| 判定行不看阶段 | 只改承重文件 / 空转计入 / 评审不算 / 旧提交单独计数 |
| 判定行不排除异议 | **只有**异议不算那条 |
| 承重文件改动不算交付 | **只有**只改承重文件那条 |
| 未判定不计 | **只有**旧提交单独计数那条 |

"判定行只在空转时写"我用的变异形状和你的不同(`("\n%s: 是" % …) if idle else ""`),
红的是同样两条 —— 那条用例专门为打这种实现而写,它确实只被这两条抓住。


## 四、未覆盖(不构成打回)

**① 自由文本旗标能伪造判定行 —— 核过,危险的方向被 W14 自己堵住了。** `--doc-reason` 等旗标的
值会原样进正文,带换行就能在行首写出 `空转判定: …`,而 `report` 取第一处匹配。但一个**空转**的
impl 回合里,五个旗标**没有一个能生效**(没改角色路径、没改承重文件、不在完成、删不了测试),
所以正文里根本不会出现自由文本 —— 伪造只能把一个不空转的回合写成"是",方向是**多计开销**,
不是"让指标好看"。不改;若要彻底,`report` 取最后一处匹配即可。
