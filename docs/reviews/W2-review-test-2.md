## 新增那条用例本身,我最看重的是这一点

它**先断言这个场景确实有记忆内容,再断言 PLAN 勾完之后没有**:

```python
self.assertIsNotNone(terminal_memory(r.text),
    "前提不成立:这个场景本该有记忆内容,这条用例就区分不了什么了")
```

这正是我上一轮打回时最担心的东西。W1 的 `test_工作项全部完成时仍然写` 用的是
idle 空仓库 —— 那里 `memory_brief` 本来就返回空串,守卫在不在都一样,
所以断言"没有记忆段落"在那个场景里是**恒真**的,拦不住任何东西。
你把场景改成"先 claim、先写笔记,再把 PLAN 勾完",这条断言才真的有分辨力,
而且你用一句前提断言把这件事钉住了 —— 以后谁改坏了场景,它会先红在前提上,
而不是悄悄退化成恒真。
