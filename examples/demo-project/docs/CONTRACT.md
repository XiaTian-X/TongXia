# 接口契约（冻结 — agent 只读，变更需双方同意后由人类修改）

> **这是整套机制的承重墙。**
>
> 两个 agent 从不交谈,只通过这份契约对齐。契约含糊 → tester 测
> `login() -> token`,dev 写 `authenticate() -> Session`,两边各自都"对",
> 合起来是废的。这是唯一会让整个项目失败的方式。
>
> 规则:**没写进这份文件的东西,tester 不许断言。**

## slugify

- 依据: 人类定稿

### `slugify(text: str) -> str`

**行为** 把任意文本转成适合放进 URL 的 slug。

**参数约束**

| 参数 | 类型 | 约束 |
|---|---|---|
| `text` | `str` | 非空;去除首尾空白后仍非空 |

**返回** 仅含 `a-z`、`0-9` 和 `-` 的字符串;不以 `-` 开头或结尾;
不含连续的 `-`。

**错误**

| 条件 | 抛出 |
|---|---|
| `text` 去除首尾空白后为空 | `ValueError` |
| `text` 不是 `str` | `TypeError` |

**边界情况**
- 连续空白折叠成单个 `-`
- 非字母数字字符(标点、符号)直接丢弃,不转成 `-`
- 大写字母转小写;非 ASCII 字符原样保留并转小写

## truncate

- 依据: 人类定稿

### `truncate(text: str, n: int) -> str`

**行为** 若 `text` 长度超过 `n`,截断并以 `…`(U+2026)结尾。

**参数约束**

| 参数 | 类型 | 约束 |
|---|---|---|
| `text` | `str` | 可为空串 |
| `n` | `int` | `>= 1` |

**返回** 长度不超过 `n` 的字符串。省略号**计入**长度:`n=5` 时最多
4 个原文字符加一个 `…`。

**错误**

| 条件 | 抛出 |
|---|---|
| `n < 1` | `ValueError` |
| `text` 不是 `str` 或 `n` 不是 `int` | `TypeError` |

**边界情况**
- `len(text) == n` 时原样返回,不加省略号
- 空串原样返回
